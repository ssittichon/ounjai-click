# AI Oun Jai Clickable Web Mockup V3

## การปรับปรุงจาก V2
- Caregiver Report แสดงบันทึกแยกตามกิจกรรม
- Caregiver Summary มีช่องบันทึกเพิ่มเติมและบันทึกเข้า Report
- ปุ่มคำใบ้ใช้ Hint Sequence ที่ต่างกันตามกิจกรรม
- คำใบ้เพิ่มทีละระดับ แทนการแสดงข้อความเดิม
- เพิ่มคำอธิบายวิธีใช้ข้อมูลสรุปอย่างระมัดระวัง
- ระบุชัดว่าจำนวนคำใบ้ เวลา และจำนวนข้อที่ทำจบ ใช้เพื่อปรับ UX/ระดับการช่วยเหลือ ไม่ใช่การประเมินทางคลินิก

## วิธีเปิด
1. แตกไฟล์ ZIP
2. เปิด `index.html`
3. ทดลองกิจกรรม
4. ที่หน้า Caregiver Summary เลือกข้อสังเกต เขียนบันทึก และกดบันทึก
5. เปิด Caregiver Report จากหน้าหลักเพื่อดูบันทึกแยกตามกิจกรรม

## ขอบเขต
- ใช้ข้อมูลจำลองใน session ปัจจุบัน
- ไม่มีฐานข้อมูลหรือการบันทึกถาวร
- ไม่ใช้เพื่อคัดกรอง วินิจฉัย รักษา หรือประเมินโรค
