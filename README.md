# AI Oun Jai — Mockup V6 Standalone v1

Functional clickable prototype for the AI Oun Jai caregiver-assisted cognitive activity support project.

## Scope

- Non-clinical prototype only.
- Does **not** diagnose, screen, predict, treat, or score cognitive impairment/dementia.
- Interaction data in the mockup are descriptive usability/adaptation signals only.
- Caregiver remains human-in-the-loop for every recommendation through **Accept / Modify / Reject**.

## V6 features

- A1 Visual Recall — 5 Core + 1 Optional
- A2 Picture–Word / Semantic — 6 Core
- A3 Sequence Tap — 5 Core
- A4 Object Matching — 5 Core + 1 Optional
- A5 Category Sort — 4 Core + 1 Optional
- A6 Target Select — 5 Core + 1 Optional
- A7 Rule Switch — 3 Core + 2 Optional
- Hint 1–4, reset per item
- Pause / Skip / Finish without failure language
- Core → Optional gate
- Post-activity reaction + caregiver note
- Explainable rule-based recommendation
- Caregiver Accept / Modify / Reject
- Caregiver Report and session close

## Copyright / content rule

The prototype uses project-created text, interaction logic, and simple SVG pictograms built from basic geometric primitives in `app.js`. It does not intentionally reuse artwork, UI assets, game level layouts, audio, or standardized cognitive-test content from third parties. Before any public/research release, every production asset should still be entered in the project Copyright Asset Register and reviewed for provenance/rights.
